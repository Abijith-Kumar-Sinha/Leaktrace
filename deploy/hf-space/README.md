# LeakTrace API

This is the decoder backend for the LeakTrace demo. The frontend is the GitHub Pages site of the
[Abijith-Kumar-Sinha/Leaktrace](https://github.com/Abijith-Kumar-Sinha/Leaktrace) fork.

**Investigative lead, not proof.** All accuracy figures to date come from simulation, and the demo uses mock papers only.
Cases are kept in temporary storage and disappear whenever the Space restarts.
